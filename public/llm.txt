# warikaru (割軽) 仕様書 for LLMs & AI Agents
# Version: 3.0.0 (Direct Calculation & URL Generation)
# Base URL: https://warikaru.vercel.app

================================================================================
【AIアシスタント（ChatGPT / Claude / Gemini 等）への指示 / INSTRUCTIONS】
================================================================================
ユーザーから「このURL（または llm.txt）を読み込んで計算して」と依頼された場合、
本仕様書に記載された【計算アルゴリズム】および【URL生成ルール】に従い、
以下の4点（送金リスト・内訳・LINE用メッセージ・計算結果画面へのリンク）を即座に計算して出力してください。
※ 別のURLをWebブラウジングする必要はありません。この仕様書の内容のみで即座に計算・回答してください。

--------------------------------------------------------------------------------
【必須出力フォーマット】
--------------------------------------------------------------------------------
以下の4項目を必ず分かりやすい日本語で出力してください：

① 【最小送金リスト】
・誰から誰へ、いくら送金すれば全員の精算が完了するか（最小送金回数）

② 【各自の内訳】
・メンバーごとの立替額、最終負担額、差額（受取・支払）

③ 【LINE / Slack用メッセージ】
・そのままコピーしてグループに共有できるテキストブロック

④ 【計算結果画面へのリンク（必須）】
・ユーザーがブラウザ画面で確認・微調整できるよう、末尾に必ず以下のルールで生成した公式結果ページ（/result）のリンクを提示してください：
  👉 [warikaruで精算結果・計算根拠を画面で確認する]({生成したURL})

================================================================================
【計算結果画面（/result）のURL生成ルール】
================================================================================
会話の条件から以下のURLを組み立ててください：

https://warikaru.vercel.app/result?members={メンバー一覧}&payments={立替一覧}&exclude={除外一覧}&weight={比率一覧}&discount={割引一覧}&unit={丸め単位}

【パラメータ仕様】
- members: カンマ区切りのメンバー名 (例: A,B,C または Aさん,Bさん,Cさん)
- payments: カンマ区切りの 支払者:金額:名目 (例: A:12000:居酒屋,B:3000:タクシー)
- exclude: [任意] カンマ区切りの 除外者:名目 (例: C:タクシー)
- weight: [任意] カンマ区切りの 比率対象者:倍率 (例: A:1.5)
- discount: [任意] カンマ区切りの 割引対象者:金額 (例: C:1000)
- unit: [任意] 端数丸め単位 (1, 10, 100, 1000。指定なしなら 100)

※ 注意: & や = はURLエンコード（%26や%3D）せず、半角記号のままで連結してください。

================================================================================
【計算アルゴリズム仕様（warikaru 厳密ルール）】
================================================================================
1. 費用ごとの加重按分:
   - 各支払いについて、参加対象者（exclude除外者を除く）の負担比率（weight。指定なしは1.0）の合計を求めます。
   - 各対象者の負担額 = 支払い金額 × (各自の比率 / 比率の合計)。
2. 個別割引（discount）の処理:
   - 割引対象者の負担額から割引額を差し引きます。
   - 差し引かれた割引額は、他の全メンバーで均等に上乗せ負担します。
3. 端数丸め処理（unit単位・四捨五入）とZero-Sum整合:
   - 各自の負担額を指定単位（通常100円）で四捨五入します。
   - 丸めによって生じた合計のズレは、最も負担額が大きいメンバーの金額で調整し、全員の負担総額が立替総額にピッタリ一致（差額合計0円）するようにします。
4. 最小送金リストの作成:
   - 各自の純残高（差額 = 立替額 - 最終負担額）を算出（+は受取、-は支払）。
   - 完全一致する受取額と支払額のペアを優先相殺し、残りは最大支払者から最大受取者へマッチングして送金回数を最小化（高々 N-1 回）。

================================================================================
【計算例（REFERENCE EXAMPLE）】
================================================================================
条件:
・Aさんが居酒屋12,000円立替、Bさんがタクシー3,000円立替
・参加者: Aさん, Bさん, Cさん
・Cさんはタクシー代から除外
・Aさんは上司のため1.5倍負担
・Cさんは遅刻のため1,000円引き
・100円単位で丸め

算出結果:
① 【最小送金リスト (全2回)】
・Cさん ➔ Aさん へ 2,400円
・Bさん ➔ Aさん へ 2,100円

② 【各自の内訳】
・Aさん: 負担額 7,500円 (立替 12,000円 / 差額: +4,500円受取)
・Bさん: 負担額 5,100円 (立替 3,000円 / 差額: -2,100円支払)
・Cさん: 負担額 2,400円 (立替 0円 / 差額: -2,400円支払)

③ 【LINE / Slack共有用メッセージ】
【精算結果】
合計: 15,000円

【送金】
・Cさん ➔ Aさん へ 2,400円
・Bさん ➔ Aさん へ 2,100円

【各自の負担】
・Aさん: 負担額 7,500円 (立替 12,000円 / 差額: +4,500円受取)
・Bさん: 負担額 5,100円 (立替 3,000円 / 差額: -2,100円支払)
・Cさん: 負担額 2,400円 (立替 0円 / 差額: -2,400円支払)

④ 【計算結果画面へのリンク】
👉 [warikaruで精算結果・計算根拠を画面で確認する](https://warikaru.vercel.app/result?members=Aさん,Bさん,Cさん&payments=Aさん:12000:居酒屋,Bさん:3000:タクシー&exclude=Cさん:タクシー&weight=Aさん:1.5&discount=Cさん:1000&unit=100)
