# warikaru (割軽) Specification for LLMs & AI Agents
# Version: 2.1.0 (Web Browsing & Zero-Refusal Optimized)
# Base URL: https://warikaru.vercel.app

================================================================================
【AIアシスタント（ChatGPT / Claude / Gemini 等）への指示 / INSTRUCTIONS】
================================================================================
ユーザーが「このURL（または llm.txt）に従って計算して」と指示してきた場合、
以下の手順で【送金リスト・各自の内訳・LINE用メッセージ・計算結果画面へのリンク】を出力してください。

--------------------------------------------------------------------------------
STEP 1: 公式結果ページ（/result）のURLを組み立てる
--------------------------------------------------------------------------------
会話から抽出した条件に基づき、以下のURLを組み立ててください：

https://warikaru.vercel.app/result?members={メンバー一覧}&payments={立替一覧}&exclude={除外一覧}&weight={比率一覧}&discount={割引一覧}&unit={丸め単位}

【重要：パラメータ区切り文字のルール】
「&」や「=」は絶対にURLエンコード（%26 や %3D）しないでください！
半角の「&」と「=」のままで連結してください。

【パラメータ仕様】
- members: カンマ区切りのメンバー名 (例: A,B,C)
- payments: カンマ区切りの 支払者:金額:名目 (例: A:12000:居酒屋,B:3000:タクシー)
- exclude: [任意] カンマ区切りの 除外者:名目 (例: C:タクシー)
- weight: [任意] カンマ区切りの 比率対象者:倍率 (例: A:1.5)
- discount: [任意] カンマ区切りの 割引対象者:金額 (例: C:1000)
- unit: [任意] 端数丸め単位 (1, 10, 100, 1000。指定なしなら 100)

【URLの具体例】
例1 (居酒屋12000円、タクシー3000円、Cタクシー除外、A1.5倍、C1000円引、100円丸め):
https://warikaru.vercel.app/result?members=A,B,C&payments=A:12000:居酒屋,B:3000:タクシー&exclude=C:タクシー&weight=A:1.5&discount=C:1000&unit=100

例2 (Aが4000円、Bが3000円、Cは500円引き、100円丸め):
https://warikaru.vercel.app/result?members=A,B,C&payments=A:4000:食事,B:3000:移動&discount=C:500&unit=100

--------------------------------------------------------------------------------
STEP 2: 精算結果の取得と出力（回答を拒否・保留しないこと）
--------------------------------------------------------------------------------
1. Webブラウジングツールを使用できる場合は、上記で組み立てたURLを開いて確定結果HTMLを読み取ってください。
2. もしブラウジングツールの環境制約等でページの本文が直接取得できない場合でも、回答を拒否・保留せず、以下の【計算アルゴリズム仕様】に従って計算して出力してください。

【必須出力項目】
以下の4点を必ず日本語で分かりやすく出力してください：
① 【最小送金リスト】誰から誰へ、いくら送金すれば完了するか（最小送金回数）
② 【各自の内訳】立替額、最終負担額、差額（受取・支払）
③ 【LINE / Slack用テキスト】そのままコピーして送れるテキストブロック
④ 【計算結果画面へのリンク】
   ユーザーがブラウザ画面で確認・微調整できるよう、末尾に必ず組み立てたURLリンクを記載してください：
   👉 [warikaruで精算結果・計算根拠を確認する]({組み立てたURL})

--------------------------------------------------------------------------------
【計算アルゴリズム仕様（フォールバック用）】
--------------------------------------------------------------------------------
1. 費用ごとの個別負担額:
   - 各支払いについて、参加対象者（exclude除外者を除く）の間で按分します。
   - weight（比率）が指定されている場合、その比率（例: 1.5倍）に応じて加重按分します。
2. 割引（discount）の処理:
   - 割引対象者の負担額から割引額を差し引きます。
   - 割引された金額は、他の全メンバーで均等に上乗せ負担します。
3. 端数処理（丸め・差額補正）:
   - 指定された単位（例: 100円単位）で四捨五入します。
   - 丸めによって生じた合計のズレは、最も負担額が大きいメンバーの金額で調整し、全員の純残高（立替額 - 負担額）の合計が厳密に「0円（Zero-Sum）」になるよう保ちます。
4. 最小送金回数の最適化:
   - 全員の純残高（Net = 立替額 - 負担額）を算出（Net > 0 は受取、Net < 0 は支払）。
   - 完全一致する受取額と支払額のペアがあれば優先相殺。
   - 残りは最大支払者から最大受取者へマッチングして送金（高々 N-1 回で完了）。
