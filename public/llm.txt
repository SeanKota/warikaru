# warikaru (割軽) API Specification for LLMs & AI Agents
# Version: 2.0.0 (GET-First & Web Browsing Optimized)
# Base URL: https://warikaru.vercel.app

================================================================================
【AIアシスタント（ChatGPT / Claude / Gemini 等）への直接指示 / DIRECT INSTRUCTIONS】
================================================================================
ユーザーが「このURL（または llm.txt）に従って計算して」と指示してきた場合：

1. 【GET方式のみを使用してください】
   この計算エンジンは「GETリクエスト（Webブラウジング）」に完全特化しています。
   複雑なPOSTリクエスト送信は一切不要です。

2. 【実行手順】
   ユーザーの会話から条件を抽出し、以下の公式結果ページ（/result）のURLを組み立てて直接Webブラウジング（Web閲覧）してください：

   【URL組み立てルール】
   https://warikaru.vercel.app/result?members={メンバー一覧}&payments={立替一覧}&exclude={除外一覧}&weight={比率一覧}&discount={割引一覧}&unit={丸め単位}

   【パラメータ仕様】
   - members: カンマ区切りのメンバー名 (例: A,B,C)
   - payments: カンマ区切りの 支払者:金額:名目 (例: A:4000,B:3000 または A:12000:居酒屋,B:3000:タクシー)
   - exclude: [任意] カンマ区切りの 除外者:名目 (例: C:タクシー)
   - weight: [任意] カンマ区切りの 比率対象者:倍率 (例: A:1.5)
   - discount: [任意] カンマ区切りの 割引対象者:金額 (例: C:500 または C:1000)
   - unit: [任意] 端数丸め単位 (1, 10, 100, 1000。指定なしなら 100)

   【URLの具体例】
   例1 (Aが4000円、Bが3000円、Cは500円引き):
   https://warikaru.vercel.app/result?members=A,B,C&payments=A:4000,B:3000&discount=C:500&unit=100

   例2 (居酒屋12000円、タクシー3000円、Cタクシー除外、A1.5倍、C1000円引き):
   https://warikaru.vercel.app/result?members=A,B,C&payments=A:12000:居酒屋,B:3000:タクシー&exclude=C:タクシー&weight=A:1.5&discount=C:1000&unit=100

3. 【結果の取得と出力】
   上記URLをWebブラウジングすると、warikaruエンジンが計算した確定送金指示と各自の内訳HTMLが表示されます。
   暗算は絶対にせず、そのWebページに表示された以下の4点をユーザーに提示してください：
   ① 【送金指示】誰から誰へ、いくら送金するか（最小送金回数）
   ② 【各自の内訳】立替額、負担額、貸し借り差額
   ③ 【LINE / Slack共有用テキスト】
   ④ 【計算結果画面へのリンク（必須）】
      ユーザーがChatGPT外のブラウザ画面で計算根拠や明細を確認・微調整できるよう、回答の末尾に必ず組み立てたURLリンクを記載してください：
      例: 👉 [warikaruで精算結果・計算根拠を画面で確認する]({組み立てたURL})

================================================================================
1. PURPOSE & ALGORITHM (アプリの目的とアルゴリズム)
================================================================================
LLMによる暗算ミス・1円単位の端数不整合・多人数間の循環送金をゼロにするための決定論的精算エンジンです。
- 全員の貸し借り差額の総和は厳密に 0 円（数学的整合性保証）
- 貪欲法（Greedy Algorithm）と完全一致相殺（Exact-Match）により、送金回数を高々 N-1 回に最小化

APIエンドポイント（JSON形式）:
GET https://warikaru.vercel.app/api/calculate?members=A,B,C&payments=A:4000,B:3000&discount=C:500&unit=100&format=text
POST https://warikaru.vercel.app/api/calculate (JSON payload)
